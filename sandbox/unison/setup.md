# Codebase for PL World sandbox runs

Run at image build time (with network) by `ucm transcript --save-codebase-to /opt/plw-unison/codebase`. Public
releases on Unison Share install without logging in.

```ucm
scratch/main> project.create-empty plw
plw/main> lib.install @unison/base/releases/7.19.2
plw/main> ls lib
```
